Service Control Dashboard

📝 Quick Start Instructions

This dashboard helps you manage your Easy Picsy services. You can also use the terminal:

  • ./start-services.sh - Interactive menu
  • ./start-services.sh frontend - Start frontend only
  • ./start-services.sh backend - Start backend only
  • ./start-services.sh both - Start both services
  • ./start-services.sh db - Open database studio

Note: Commands will run in your terminal. Keep the terminal window open while services are running.
